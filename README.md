# Odd Power Series Calculator 
This project calculates the sum of a mathematical series where i takes odd values from 1 to 2n-1 and each term is i divided by x raised to the power of (i+1).

## What I Learned 
- How to use the pow() function from math.h
- How to iterate over odd numbers using i+=2
- How to calculate mathematical series with loops
- How to combine integer and float inputs in one program
